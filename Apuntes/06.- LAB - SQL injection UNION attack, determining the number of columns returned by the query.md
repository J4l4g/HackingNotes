El objetivo del laboratorio es determinar el numero de columnas que contiene la tabla
Lo primero que deberemos de hacer al acceder es añadir la URL al scope de BurpSuite, para no perder ninguna petición y así poder mapear mejor la web.

A continuación lo que observamos es que en la campo de las categorías a la hora de filtrar se realiza una consulta *SQL* lo primero que haremos será ver si devuelve algún error al añadir un carácter especial

En este caso nos muestra un código de error `500` *Internal Server Error*, probaremos a enumerar columnas con el método de `ORDER BY`
![[Pasted image 20261028125009.png]]

Devolviéndonos un código de estado `200` probaremos a cambiar el valor de la columna hasta conseguir un error o alguna respuesta inesperada por parte de la web

Descubrimos que con el valor `4` nos devuelve un código de error `500` *Internal Server Error*
