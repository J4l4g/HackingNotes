*Esta herramienta esta dedicada para el barrido de la red y la enumeración de diferentes host en esta*

```bash
fping -asgq <IP/mascara>
```

| Opciones | Usos                               | + Info |
| -------- | ---------------------------------- | ------ |
| *-a*     | Objetivos activos                  |        |
| *-s*     | Imprimir estadisticas por pantalla |        |
| *-g*     | Lista de objetivos                 |        |
| *-q*     | Silencioso                         |        |
