#Enumeration #SMBEnumeration #RecursosCompartidos 

*Esta herramienta nos permite hacer enumeraciones de las maquinas victimas directamente desde nuestra maquina Linux pudiendo utilizar o no credenciales validas.*
###### Obtener política de contraseñas
```bash
enum4linux -P <ip>
```

| OPCIONES | FUNCION                                           | +Info |
| -------- | ------------------------------------------------- | ----- |
| *-a*     | IP objetivo                                       |       |
| *-v*     | Verbose                                           |       |
| *-P*     | Obtener información de la política de contraseñas |       |
