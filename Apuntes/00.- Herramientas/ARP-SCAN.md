#Enumeration #RedEnumeration

*Esta herramienta esta dedicada para el barrido de la red y la enumeración de diferentes host en esta*

``` bash
arp-scan -I <Interfaz> --localnet
```

| OPCIONES       | FUNCION                                       | +Info |
| -------------- | --------------------------------------------- | ----- |
| *-I*           | Interfaz de escaneo                           |       |
| *--localnet*   | Activos dentro de nuestra red local (Alcance) |       |
| *--ignoredups* | Ignorar duplicados                            |       |
