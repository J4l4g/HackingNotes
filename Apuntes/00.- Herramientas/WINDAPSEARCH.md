#Enumeracion #AD #LDAP

Enumeración del Active Directory a través del LDAP.

| OPCIONES | FUNCION                                    | +Info |
| -------- | ------------------------------------------ | ----- |
| *-dc-ip* | IP objetivo                                |       |
| *-u*     | Usuario                                    |       |
| *-p*     | Contraseña                                 |       |
| *--da*   | Enumerar miembros del grupo Domain Admin   |       |
| *-PU*    | Enumerar usuarios con privilegios elevados |       |
|          |                                            |       |
