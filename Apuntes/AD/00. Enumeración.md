## Que soy?

Deberemos de saber al principio de todo quienes somos y pertenecemos al grupo de Administradores
```PowerShell
whoami
```

```PowerShell
net localgroup Administrators
```

## Cuantos servidores y equipos hay en el entorno
```PowerShell
Get-NetComputer | Select-Object name, operatingsystem, operantingsystemversion, dnshostname
```

## Usuarios del dominio
```PowerShell
Get-NetUser | Select-Object samaccountname, name, description, memeberof, lastlogon, pwdlastset, badpwdcount | Format-Table -Autosize
```

## Domain Admins
```PowerShell
Get-DomainGroupMember -Identity "Domain Admins" | Select-Object GroupNAme, MemberNAme, MemberDomain, IsGroup | Format-Table -AutoSize
```

## Constrain Delegation
```PowerShell
Get-NetComputer -TrustedToAuth | Slect-Object name, msds-allowedtodelegateto | Format-List
```

## Relaciones de Confianza
```PowerShell
Get-DomainTrust | Select-Object SourceName, TargetName, TrustType, TrustDirection | Format-Table -Autosize
```

## Cuentas con derechos de Replicacion (DCSync)
```PowerShell
Get-DomainObjectAcl -SearchBase "DC=enterprise,DC=com" -ResolveGUIDs |
    Where-Object {
        $_.ObjectAceType -eq "DS-Replication-Get-Changes-All"
    } |
    Select-Object ObjectAceType,
                  AceQualifier,
                  @{
                      Name='Identity';
                      Expression={ConvertFrom-SID $_.SecurityIdentifier}
                  } |
    Format-Table -AutoSize
```

## Encontrar recursos compartidos donde tenemos permisos de escritura

Deberemos de importar la herramienta de *PowerHunShares*
```ad-warning
Esta herramienta no se puede ejecutar en una maquina que tenga invocado el *PowerView* Y deberemos de tener una nueva shell aparte
```
```shell
Import-Module .\PowerHuntShares.psm1
```

```shell
Invoke-HuntSMBShares -NoPing -OutputDirectory C:\Ad\Tools -Hostlist .\servers.txt
```
