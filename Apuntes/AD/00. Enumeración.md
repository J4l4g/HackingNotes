## Que soy?

Deberemos de saber al principio de todo quienes somos y pertenecemos al grupo de Administradores
```PowerShell
whoami
```

```PowerShell
net localgroup Administrators
```

## Cuantos servidores y equipos hay en el entorno
```PowerShell
Get-NetComputer | Select-Object name, operatingsystem, operantingsystemversion, dnshostname
```

## Usuarios del dominio
```PowerShell
Get-NetUser | Select-Object samaccountname, name, description, memeberof, lastlogon, pwdlastset, badpwdcount | Format-Table -Autosize
```

## Domain Admins
```PowerShell
Get-DomainGroupMember -Identity "Domain Admins" | Select-Object GroupNAme, MemberNAme, MemberDomain, IsGroup | Format-Table -AutoSize
```
