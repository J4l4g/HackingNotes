*Herramienta utilizada para la enumeración de usuarios validos en un host objetivo.*

###### Enumeración de usuarios validos
```bash
kerbrute userenum -d <Nombre_Dominio> --dc <IP> </ruta/wordlist> -o <archivo_salida>
```

| Opciones   | Usos                    | + Info |
| ---------- | ----------------------- | ------ |
| *userenum* | Enumeración de usuarios |        |
| *-d*       | Domain Name             |        |
| *--dc*     | IP / Domain Controller  |        |
| *-o*       | Fichero de salida       |        |
