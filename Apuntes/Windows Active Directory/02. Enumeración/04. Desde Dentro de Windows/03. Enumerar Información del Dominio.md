Para enumerar información del dominio podemos usar algunas opción de una gran lista alguna mas relevante es
Información de los requisitos de contraseñas `net accounts`
Política de contraseñas `net accounts /domain`
Información sobre grupos `net group /domain`
Listar usuarios con  privilegios de Administrador `net group "DomainAdmins" /doamin`

Para evadir las alertas a en los sistemas de detección podemos sustituir el uso del comando `net` por el uso del comando `net1` que nos ejecuta lo mismo pero siendo así mas sigiloso.
