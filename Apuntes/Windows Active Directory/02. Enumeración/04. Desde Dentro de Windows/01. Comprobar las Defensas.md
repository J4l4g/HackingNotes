# Firewall
Con `netsh advfirewall show allprofiles` nos mostrara toda la información sobre el firewall, incluyendo alguna parte de su configuración

# Windows Defender
Para ver la información de este lo haremos desde la `CMD` ejecutando `sc query windefend` para verificar si este se esta ejecutando.
Para verificar el estado y la configuración usaremos desde `Power Shell` el siguiente comando `Get-MpComputerStatus`
