# CMD
Enumerar nombre de equipo `hostname`
Configuración de red `ipconfig /all`
Variables de entorno `set`
Nombre del host de dominio `echo %USERDOMAIN%`
Nombre controlador de dominio `echo %logonserver%`
Todo lo anterior `systeminfo

# PowerShell
Enumerar los módulos disponibles para el uso `Get-Module`
Política de ejecución `GetExecutionPolicy Bypass -Scope Process`
Valores de entorno `Get-ChildItem Env: | ft Key,Value`
