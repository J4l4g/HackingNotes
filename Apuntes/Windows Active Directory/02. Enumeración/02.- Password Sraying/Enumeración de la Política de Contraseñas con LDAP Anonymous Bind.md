## Desde Linux
Para enumerar las políticas de contraseñas usando el protocolo *LDAP* podemos usar herramientas como `WINDAPSEARCH.py`, `LDAPSEARCH` y `AD-LDAPDOMAINDUMP.py`

#### LDAPSEARCH
La herramienta [[LDAPSEARCH]] nos permite hacer la enumeración de políticas contraseñas desde una maquina Linux hacia el servicio LDAP.
