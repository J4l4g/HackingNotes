En este caso se nos indica que hay una filtración a través de ficheros de backup en un directorio oculto. Teniendo que identificar la contraseña de la base de datos.

Lo primero que hacemos es activar el proxy del navegador y abrir Burpsuite, en este caso nos encontramos con una web que simula una tienda online, buscaremos en búsqueda de información que se nos pueda aportar que sea valiosa ya que lo único que sabemos es que hay un directorio oculto.
Buscaremos si hay un `Robots.txt` expuesto
![[Pasted image 20261020190503.png]]

En caso de no querer hacerlo manualmente en Burpsuite podemos enumerar los directorios accediendo a `Target` -> `Engagement tools` -> `Content Discovery`, donde conseguimos enumerar el directorio oculto
![[Pasted image 20261020191105.png]]

Navegaremos a la ubicación que se supone que esta deshabilitada para acceder en este caso `/backup`
![[Pasted image 20261020190547.png]]

Y en el encontramos un archivo `.bak` en el cual a la hora de acceder a leer el código de este
![[Pasted image 20261020190655.png]]
