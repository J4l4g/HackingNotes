#InformationDisclosure #BSCP #HTTP-TRACE #Headers #Match-and-Replace
En este laboratorio se aplica una vulnerabilidad de omisión de autenticación, que no es practica explotarla sin el conocimiento de una cabecera HTTP personalizada usada por el front-end.
Tendremos que obtener el nombre del encabezado, usarlo para omitir la autenticación acceder a la interfaz de administración y eliminar al usuario `carlos`

Lo primero que tendremos que hacer es analizar frente a lo que nos encontramos, en este caso nos encontramos delante de una simulación de una web online con un panel de usuario al cual podemos acceder usando las credenciales de `wiener:peter`

Sabemos que tendremos que acceder a un panel de administración pero no sabemos donde se encuentra este haremos una enumeración de directorios de la web accediendo a `Target` -> `Engagement tools` -> `Content Discovery` en el encontramos el directorio `/admin`

Se nos indica que el panel de admin solo esta disponible para usuarios locales
Probaremos a usar la cabecera `TRACE` la cual nos permite verificar, depurar y comprobar que información esta llegando realmente al servidor
![[Pasted image 20261020194145.png]]

En La respuesta identificamos el uso de la cabecera `X-Custom-IP-Authorization`, la cual se utiliza para identificar desde donde se esta haciendo al solicitud
![[Pasted image 20261020194525.png]]

En este caso se muestra nuestra IP, como en el mensaje de error se nos indica que solo se puede acceder al panel de admin desde los usuarios local (localhost) modificaremos las peticiones para que indique que las solicitudes son provenientes de la red local
Para ello accederemos a a `Proxy` -> `Match and Replace` -> `Add` en el tipo indicaremos `Request header` y en `Replace` indicaremos lo que queremos añadir a las solicitudes en este caso la cabecera personalizada indicando el localhost
![[Pasted image 20261020195005.png]]

Ahora al estar modificando las peticiones en tiempo real al vorver a la pagina de inicio de la web se nos permiteri el acceso al panel de administracion ya que es como si estuvisesemos en la red local
![[Pasted image 20261020195124.png]]

Accederemos y eliminaremso al ususario `carlos`
