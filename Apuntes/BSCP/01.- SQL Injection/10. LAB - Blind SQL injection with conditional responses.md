#BSCP #SQLinjection #Blind

En este laboratorio se nos pide encontrar la contraseña del usuario `administrator` que se encuentra en la tabla `users` con las columnas `username` y `password`

Lo primero que hacemos al tramitar las primeras peticiones es darnos cuenta que la aplicación cuando devuelve una respuesta positiva nos lo demuestra incluyendo en la respuesta el mensaje de *Welcome Back!*![[Pasted image 20261029204801.png]]

En esta petición también nos damos cuenta de que hay una cabecera de `Cookie` en la que hay un identificador llamado `TrackingId` vamos a comprobar si este campo es un campo inyectable introduciendo una orden booleana en la que se iguale esta a una operación numérica
![[Pasted image 20261029205050.png]]

Al hacer `1=2` no recibimos ese mensaje de *Welcome back!* pero a la hora de igualar `1=1` si que obtenemos esta respuesta
![[Pasted image 20261029205333.png]]

Ahora ya sabemos que 110% es una inyeccion booleana, como conocemos el nombre de la tabla, sus columnas y el nombre del usuario que buscamos vamos a conseguri la password
![[Pasted image 20261029205531.png]]

Probamos con las letras del abecedario y descubrimos que la letra final no es mayor a la letra `g`
![[Pasted image 20261029205706.png]]

Y que la primera letra es mayor a `a` en orden alfabéticamente, ahora debremos de saber cual es la primera coincidencia 
![[Pasted image 20261029210426.png]]

Encontramos que la primera coincidencia es la letra `h`, como las contraseñas pueden ser muy largas vamos a crear un pequeño script que nos permita descifrar la contraseña automaticamente.
