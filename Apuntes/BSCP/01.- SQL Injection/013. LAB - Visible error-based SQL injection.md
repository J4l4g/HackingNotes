#BSCP #SQLinjection #Visible

En este laboratorio se nos pide, obtener las credenciales del usuario `administrator` que se encuentra en la tabla `users` en la columnas `username` y `password`

En una petición nos encontramos con un campo cookie diferente, este se llama `TrackingId` y es un posible campo vulnerable, probaremos a añadirle una `'` en búsqueda de que se nos devuelva algún error
![[Pasted image 20261105104003.png]]

En este caso el error nos indica
```error
Unterminated string literal started at position 52 in SQL SELECT * FROM tracking WHERE id = 'cFtgq0O2jbxLCi73''. Expected  char
```

En esta consulta nos esta mostrando un error debido a que se ha abierto una nueva cadena de texto, la cual ni tiene contenido ni esta cerrada.
Vamos a probar a comentar el resto de la consulta y ver si se enos mantiene el error
![[Pasted image 20261105104415.png]]

Al comentar el resto de al consulta no obtenemos el error que se nos había devuelto antes.

Ahora vamos a proceder a realizar una conversión de tipos y ver la respuesta por parte de SQL.
```sql
' AND CAST((SELECT 1) AS int)--
```
![[Pasted image 20261105104834.png]]

Recibimos un error que nos indica que el argumento que se pase a través de `AND` tiene que ser de tipo booleano y no de tipo `int`

Para que esta condición que nos pide SQL que se tiene que cumplir se cumpla deberemos de igualar el `CAST` que se encarga de convertir el numero a un numero entero lo tendremos que igualar al mismo valor de este (Seria semejante a hacer un 1=1) que es una condicion booleana de `TRUE` o `FALSE`
```sql
' AND 1=CAST((SELECT 1) AS int)--
```
![[Pasted image 20261105105452.png]]

De esta forma ya no recibimos el error
Ahora deberemos de adaptar la petición para que nos obtenga los datos del usuario `administrator`
```sql
' AND 1=CAST((SELECT username FROM users) AS int)--
```
![[Pasted image 20261105105934.png]]

Al ser una petición demasiado larga no se tramita completa como podemos observar, así que deberemos de eliminar el contenido de `TrackingId`
![[Pasted image 20261105110107.png]]

Ahora el error que se nos devuelve es por que mas de una fila se nos esta devolviendo, por lo cual no se puede devolver completa.

Usaremos un limitador `LIMIT 1` para obtener unicamente la primera fila
```sql
' AND 1=CAST((SELECT username FROM users LIMIT 1) AS int)--
```
![[Pasted image 20261105110308.png]]

Ahora nos devuelve un error de salida ya que no nos puede devolver la salida tipo `int` ya que es un `varchar` pero obtenemos el nombre del usuario que buscábamos, ahora deberemos de obtener la contraseña de este.
```sql
' AND 1=CAST((SELECT password FROM users LIMIT 1) AS int)--
```
![[Pasted image 20261105110434.png]]
