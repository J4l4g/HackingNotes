
En este laboratorio conocemos una tabla llamada `users` con las columnas `username` y `password`. Deberemos obtener las credenciales del usuario `administrator`

Nada mas acceder a la web interceptamos una petición en la que encontramos que hay una cabecera `Cookie` con un valor llamado `TrackingId` sobre el cual al intentar añadir una única `'` recibimos un mensaje de error
![[Pasted image 20261103170215.png]]

Probaremos añadiendo una segunda `'` en el campo de `TrackingId` como si fuese un campo vacío, en este caso no se nos devuelve el error.
![[Pasted image 20261103170337.png]]

Esto lo que nos demuestra es que a la hora de introducir una sola `'` el campo se mantiene abierto y se produce un error, pero a la hora de cerrarlo el error no aparece por lo que la comilla abierta esta mostrando un error detectable en la respuesta.

Ahora deberemos de comprobar que el servidor este interpretando la inyección como una consulta SQL en comparación con cualquier otro tipo de error.
Para ello deberemos de realizar una inyección en la cual queremos comprobar si esta interpretando la inyección como consulta o no
```sql
'||(SELECT '')||'
```

Esta consulta utiliza la cadena original y ejecuta una subconsulta `(SELECT '')` que devuelve una cadena vacía `''`, estas salidas se concatenan `||` y al final de la ultima concatenación se añade una ultima `'` la cual al cerrarse a continuación la consulta original se convierte en una consulta vacía
![[Pasted image 20261104121221.png]]

En esta caso estamos obteniendo un error por lo que la consulta debe ser invalida, esto se puede deber al tipo de base de datos, probaremos haciendo la consulta a la tabala comun de Oracle `dual` por si es una base de datos de Oracle
```sql
'||(SELECT '' FROm dual)||'
```
![[Pasted image 20261104121429.png]]

Al no obtener errores quiere decir que la base de datos destino puede ser una base de datos Oracle, la cual requiere de las declaraciones `SELECT` especificando explícitamente el nombre de una tabla.

Ahora buscaremos forzar un error buscando hacer una supuesta enumeración de tablas, al conocer el nombre de las tablas proporcionadas por el enunciado del laboratorio vamos a hacer una pequeña prueba de enumeración, en este caso vamos a buscar por una tabla llamada `not-a-real-table`
```sql
'||(SELECT '' FROM not-a-real-table)||'
```
![[Pasted image 20261104122118.png]]

Al devolvernos un error lo que se nos esta diciendo es que la peticion esta siendo tramitada como una consulta SQL.

Ahora deberemos de hacer fuzzing en búsqueda de tablas existentes para ello usaremos la siguiente consulta

Esta consulta se encarga de validar que existe una tabla `users` y que almenos esta contine al menos una fila usando `ROWNUM = 1`, al ser Oracle se usa esta terminologia pero en otras bases de datos se usa `LIMIT` o `TOP`
