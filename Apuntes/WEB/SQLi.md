- *Mandando una `'`* -> Busca errores o anomalías que devuelva
- *Condiciones booleanes `OR 1=1`, `OR 1=2`* -> Buscar diferencias o respuestas inusuales
- *Cargas utiles que se basen en tiempio* -> Buscar diferencias en el tiempo de respuesta
- *Cargas utiles de OAST* -> Activa interacciones de red
