*PowerView* es una herramienta versátil de PowerShell, diseñada específicamente para el reconocimiento de Active Directory.

## Uso de PowerView
Lo primero que deberemos de ejecutar será *INVISHELL* lo cual no va a permitir ocultar o camuflar la ejecución de comandos en una PowerShell.

Ejecutaremos *INVISHELL* desde una CMD
```shell
C:\AD\Tools\InviShell\RunWithRegistryNonAdmin.bat
```

Iniciaremos *PowerView*
```shell
. C:\AD\Tools\Powerview.ps1
```
##### Obtener información del dominio
Recupera información sobre el dominio actual
```shell
Get-NetDomain
```
##### Enumerar controladores de dominio
Muestra todos los controladores de dominio del dominio actual
```shell
Get-NetDomainController
```
##### Listar usuarios del dominio
Muestra todos los usuarios del dominio junto con sus atributos detallados
```shell
Get-NetUser | select cn
```
##### Encuentra objetivos de alto valor
Muestra todos los usuarios marcados como administradores
```shell
Get-NetUser -AdminCount 1
```
##### Enumerar grupos de dominio
Mostrar todos los grupos del dominio
```shell
Get-NetGroup
```
##### Mostrar los miembro del grupo Domain Admins
```shell
Get-NetGroupMember -GroupName "Domain Admins"
```
##### Localizar equipos de dominio
Muestra todos los ordenadores del dominio
```shell
Get-NetComputer
```
##### Analizar las relaciones de confianza
Muestra las relaciones de confianza entre dominios
```shell
Get-NetDomainTrust
```
##### Comprobar las ACL en los objetos de Active Directory
Muestra las *ACL* para una cuenta de usuario especifica, resolviendo los GUID a nombres legibles
```shell
Get-ObjectAcl -SamAccountName "Administrator" -ResolveGUIDs
```
##### Encontrar recursos compartidos en ordenadores de dominio
Localizar las carpetas compartidas en equipos del dominio
```shell
Invoke-ShareFinder
```
##### Identificar configuración de delegación
Encuentra cuentas de usuario con nombres principales de servicio *(SPN)*, que se utilizan a menudo en ataques basados en kerberos.
```shell
Get-NetUser -SPN
```

### Enumeración de ACL/ACE
##### Enumerar ACL asociadas a un objeto especificado
```shell
Get-DomainObjectAcl -SamAccountName student1 -ResolveGUIDs
```
##### Enumerar ACL asociadas a un objeto de Active Directory
```shell
Get-DomainObjectAcl -SearchBase "LDAP://CN=DomainAdmins,CN=Users,DC=dollarcorp,DC=moneycorp,DC=local" -ResolveGUIDs -Verbose
```
##### Enumerar ACL asociadas a Administradores de dominio
```shell
Get-DomainObjectAcl -Identity "Domain Admins" -ResolveGUIDs -Verbose
```
##### Enumerar relaciones de confianza entre dominios
```shell
Get-NetDomainTrust
```
##### Enumerar ACL para una cuenta de un usuario especifico
```shell
Get-ObjectAcl -SamAccountName "Administrator" -ResolveGUIDs
```
##### Enumerar Access Control Entry (ACE) que puedan ser interesantes
```shell
Find-InterestingDomainAcl -ResolveGUIDs
```
##### Obtener las ACL donde un usuario especifico tenga permisos interesanyes
```shell
Find-InterestingDomainAcl -ResolveGUIDs | ?{$_.IdentityReferenceName -match "student867"}
```
##### Obtener las ACL de asociadas a una ruta especifica
```shell
Get-PathAcl -Path "\\dcorp-dc.dollarcorp.moneycorp.local\sysvol"
```

### Enumeración GPO
##### Enumerar las GPO del dominio actual
```shell
Get-DomainGPO
Get-DomainGPO | select displayname
Get-DomainGPO -ComputerIdentity dcorp-student1
```
##### Enumerar GPO que utilicen grupos restringidos o groups.xml para usuarios de interés
```shell
Get-DomainGPOLocalGroup
```
##### Enumerar usuarios con GPO en el grupo local
```shell
Get-DomainGPOComputerLocalGroupMapping -ComputerIdentity dcorp-student1
```
##### Enumerar maquinas donde el usuario sea miembro de un grupo especifico
```shell
Get-DomainGPOUserLocalGroupMapping -Identity student1 -Verbose
```
##### Obtener unidades organizativas en un dominio
```shell
Get-DomainOU
Get-ADOrganizationalUnit -Filter * -Properties *
```
##### Obtener la GPO aplicada a una OU
```shell
Get-DomainGPO -Identity "{0D1CC23D-1F20-4EEE...........}"
```
