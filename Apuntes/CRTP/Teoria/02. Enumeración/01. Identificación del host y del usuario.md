
## Identificación del host
Para la identificación del *host* podemos usar diferentes herramientas las cuales detallaremos su uso a continuación.
### FPING
Esta herramienta permite identificar rápidamente los host activos dentro de un rango de red.
##### Identificación de host
```shell
fping -asgq <ip/mascara>
```

- *-a* -> Mostrar solo los host activos.
- *-s* -> Imprimir estadísticas al final del escaneo.
- *-g* -> Generar una lista de destinos desde una red CIDR.
- *-q* -> Suprimir la salida para host individuales.
### NMAP
Esta herramienta permite hacer un escaneo basado en *ping* para el descubrimiento de host.
##### Identificación de host
```shell
sudo nmap -sn <ip/mascara>
```

- *-sn* -> Omite le escaneo de puertos y centrarse en el descubrimiento de host mediante envió de solicitudes ICMP.
##### Enumerar hosts activos en una lista
```shell
sudo nmap -v -A -iL hosts.txt -oN hostEnum
```

- *-v* -> Aumenta la verbosidad.
- *-A* -> Realizar la detección del sistema operativo, detección de versiones, escaneo de scripts y rastreo de rutas.
- *-iL* Pasarle un archivo de entrada con una lista de host de destino
- *-oN* -> Guardar los resultados en un formato de salida estándar
##### Escaneo completo de puertos
```shell
nmap -p- -sS --open --min-rate 5000 -vvv -Pn -n <ip> -oG scanPorts
```

- *-p-* -> Escanear los 65.535 puertos.
- *-sS* -> Realizar un escaneo TCP SYN.
- *--open* -> Mostrar solo los puertos abiertos.
- *--min-rate 5000* -> Asegúrese de una velocidad de escaneo mínima de 5000 paquetes por segundo.
- *-Pn* -> Omitir comprobaciones de ping.
- *-n* -> Omitir la resolución DNS.
- *-oG* -> Guarda los resultados en un formato compatible con grep para facilitar su análisis.


## Identificación de usuarios
Nos sirve para obtener e identificar usuarios de dominio validos.
### KERBRUTE
Es una herramienta sigilosa que nos sirve para enumerar cuentas de dominio explotando fallos de preautenticación kerberos, que a menudo evitan el registro de eventos o las alertas
##### Identificación de nombres a través de una wordlist
```shell
kerbrute userenum -d DC.LOCAL --dc <ip> usernames.txt -o valid_ad_users.txt
```
##### Extraer nombres de usuario validos de los resultados
```shell
cat valid_ad_users.txt | awk -F "VALID USERNAME:\t" '{print $2}' | tr -d ' ' | sed '/^$/d' | awk -F '@' '{print $1}' | tee users.txt
```
##### USER AS PASSWORD
```shell
kerbrute passwordspray -d DC.LOCAL --dc <ip> usernames.txt --user-as-pass
```

### POWERVIEW
##### Identificar todas las maquinas en el dominio actual donde el usuario actual tiene acceso de administrador local
```shell
Find-LocalAdminAccess -Verbose
```
##### Localizar los equipos donde un administrador de dominio (o un usuario/grupo específico) tenga sesiones
```shell
Find-DomainUserLocation -Verbose
Find-DomainUserLocation -UserGroupIdentity "RDPUsers"
```

### INVOKE-SESSIONHUNTER
Esta herramienta recupera información sobre las sesiones de usuario activas en equipos remotos pudiéndose ejecutar sin privilegios.
##### Listar sesiones de usuarios en maquinas remotas
```shell
Invoke-SessionHunter.ps1
Invoke-SessionHunter -FailSafe
Invoke-SessionHunter -NoPortScan -RawResults | select Hostname,UserSession,Access
```
