
## Identificación del host
Para la identificación del *host* podemos usar diferentes herramientas las cuales detallaremos su uso a continuación
### FPING
Esta herramienta permite identificar rápidamente los host activos dentro de un rango de red.
Su uso para identificar estos host es:
```shell
fping -asgq <ip/mascara>
```

- *-a* -> Mostrar solo los host activos
