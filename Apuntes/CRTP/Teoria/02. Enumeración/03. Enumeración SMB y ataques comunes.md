## Enumeración SMB
### NETEXEC
##### Enumerar las maquinas del dominio
```shell
nxc smb <ip/mascara>
```
##### Validar credenciales
```shell
nxc smb <ip> -u 'jdoe' -p 'Password123'
```
##### Enumeracion de maquinas validas para la conexion
```shell
nxc smb <ip/mascara> -u 'jdoe' -p 'Password123'
```
##### Enumerar recursos compartidos
```shell
nxc smb <ip> -u 'jdoe' -p 'Password123' --shares
```
##### Enumerar usuarios y grupos
```shell
nxc smb <ip> -u 'jdoe' -p 'Password123' --users
nxc smb <ip> -u 'jdoe' -p 'Password123' --groups
```
##### Volcar *LSA* y *NTDS* si tiene privilegios de administrador de dominio
```shell
nxc smb 192.168.1.1 -u 'jdoe' -p 'Password123' --lsa
nxc smb 192.168.1.1 -u 'jdoe' -p 'Password123' --ntds
```

### SMBMAP
Esta herramienta sirve para enu,erar recursos compartidos *SMB* 
##### Listar recursos compartidos con NullSession
```shell
smbmap -H corp-dc
```
##### Listar recursos compartidos con credenciales validas
```shell
smbmap -H corp-dc -u "devan" -p "P@ssword123!"
```
