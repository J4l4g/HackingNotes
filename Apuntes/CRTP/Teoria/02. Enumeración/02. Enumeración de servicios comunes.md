## LDAP y DNS
### LDAP Enumeration
#### LDAPSEARCH
##### Enumeración anonima o con credenciales
**ANONIMA**
```shell
ldapsearch -H ldap://<ip> -x -s base namingcontexts
```

**CON CREDENCIALES**
```shell
ldapsearch -H ldap://<ip> -D 'jdoe@DC.LOCAL' -w 'Password123' -x -b "DC=DC,DC=LOCAL"
```

#### LDAPDOMAINDUMP
>https://github.com/dirkjanm/ldapdomaindump

Esta herramienta la usuaremos si tenemosa credenciales para poder enumerar el LDAP de forma mas clara, permitiendonos incluso levantar un HTML para ver el contenido

```shell
ldapdomaindump -u 'DC.LOCAL\jdoe' -p 'Password123' <ip>
```

### DNS Enumeration
#### NSLOOKUP
Esta herramienta nos permite resolver nombres DNS pudiendo ver información útil sobre el objetivo
```shell
nslookup -type=SRV DC.LOCAL
```
