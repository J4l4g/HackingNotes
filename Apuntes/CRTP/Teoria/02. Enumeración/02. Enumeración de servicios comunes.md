## LDAP y DNS
### LDAP Enumeration
#### LDAPSEARCH
##### Enumeración anonima o con credenciales
**ANONIMA**
```shell
ldapsearch -H ldap://192.168.1.1 -x -s base namingcontexts
```

**CON CREDENCIALES**
```shell
ldapsearch -H ldap://192.168.1.1 -D 'jdoe@DC.LOCAL' -w 'Password123' -x -b "DC=DC,DC=LOCAL"
```
