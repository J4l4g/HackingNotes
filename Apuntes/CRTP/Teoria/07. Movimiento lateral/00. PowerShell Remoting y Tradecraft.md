 PowerShell Remoting (PSRemoting) es una herramienta usada oara la administracion tremota es muy comparada con PsExec, pero siendo mas eficienter, discreta y rapida. La herramienta utiliza WinRM.
 - Suele estar habilitada de forma predeterminada en Windows Server 2012 y en versionesd posteriores con limitaciones 
 - Escucha en los puertos 5985 y 5986
 - Recomendado para la administacion de servidores Windows Core
 - Tiene que estar habilitado el modo PSRemoting
