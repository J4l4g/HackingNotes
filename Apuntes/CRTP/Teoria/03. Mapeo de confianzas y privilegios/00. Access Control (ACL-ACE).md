
## Access Control List (ACL)
Una lista de control de acceso (ACL) es un conjunto de reglas que especifican los permisos de acceso par aun objeto en Active Directory.
Cada objeto de AD tiene una ACL asociada que determina quien puede acceder a el y que acciones puede realizar.

Dos tipos de ACL:
- Lista de control de acceso discrecional (DACL): define que usuarios y grupos tienen permitido o denegado el acceso
- Lista de control de acceso del sistema (SACL): se utiliza para auditar los intentos de acceso

### Visualizar ACL
Con el siguiente comando se pude ver la ACL para un objeto de AD especifico en este caso para el usuario *JohnDoe*
```shell
$object = Get-ADUser -Identity "JohnDoe"
(Get-Acl -Path "AD:$($object.DistinguishedName)").Access
```

## Access Control Entry (ACE)
Una entrada de control de acceso (ACE) es una regla individual dentro de una ACL que definen los permisos específicos que se otorgan o deniegan  aun usuario o grupo.
Cada ACE incluye:
- Entidad de seguridad (Usuario, grupo o equipo al que se aplican los permisos)
- Mascara de acceso (Permisos específicos como leer, escribir, eliminar, etc.)
- Tipo de acceso (Permitir o denegar)

Una ACE podría especificar:
El usuario *Alice* tiene control total sobre una Unidad Organizativa (OU).
El grupo de *HelpDesk* tiene permisos de lectura y escritura para modificar ciertos atributos de usuario.
AL usuario *Bob* se le niega explícitamente la posibilidad de eliminar un objeto.
