Una relación de confianza es un vinculo entre dos dominios o bosques que permite a los usuarios de un dominio o bosque poder acceder a los recursos del otro. Estas relaciones pueden ser automáticas (Como las relaciones padre-hijo dentro del mismo bosque) o establecerse manualmente (como las relaciones externas entre bosques)

## Enumeración
### Enumeración de Relaciones de confianza
##### Listar las relaciones de confianza del dominio actual
```shell
Get-DomainTrust
```
##### Listar las confianzas de un dominio especifico
```shell
Get-DomainTrust -Domain us.dollarcorp.moneycorp.local
```
##### Usando módulos de Active Directory
```shell
Get-ADTrust 
Get-ADTrust -Identity us.dollarcorp.moneycorp.local
```

### Enumeración del bosque
##### Obtener información sobre el bosque actual
```shell
Get-Forest 
Get-Forest -Forest eurocorp.local
```
##### Usando módulos de Active Directory
```shell
Get-ADForest 
Get-ADForest -Identity eurocorp.local
```
##### Obtener todos los dominios del bosque actual
```shell
zxGet-ForestDomain
Get-ForestDomain -Forest eurocorp.local

(Get-ADForest).Domains
```
##### Obtener todos los catálogos globales del bosque
```shell
Get-ForestGlobalCatalog
Get-ForestGlobalCatalog -Forest eurocorp.local

Get-ADForest | Select-Object -ExpandProperty GlobalCatalogs
```
#####  Mapear las relaciones de confianza entre bosques
```shell
Get-ForestTrust
Get-ForestTrust -Forest eurocorp.local

# Alternative using Active Directory module
Get-ADTrust -Filter 'msDS-TrustForestTrustInfo -ne "$null"'
```
