Una relación de confianza es un vinculo entre dos dominios o bosques que permite a los usuarios de un dominio o bosque poder acceder a los recursos del otro. Estas relaciones pueden ser automáticas (Como las relaciones padre-hijo dentro del mismo bosque) o establecerse manualmente (como las relaciones externas entre bosques)

## Enumeración
### Enumeración de Relaciones de confianza
##### Listar las relaciones de confianza del dominio actual
```shell
Get-DomainTrust
```
##### Listar las confianzas de un dominio especifico
```shell
Get-DomainTrust -Domain us.dollarcorp.moneycorp.local
```
##### Usando módulos de Active Directory
```shell
Get-ADTrust 
Get-ADTrust -Identity us.dollarcorp.moneycorp.local
```
