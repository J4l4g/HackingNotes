# Enumeracion
Para llevar a cabo este tipo de ataque de enumeración se pueden usar varias herramientas
- *Kerbrute*: Esta herramienta se usa para ataque de fuerza bruta y enumeración de cuentas validas de Active Directory mediante la preautenticacion Kerberos
- *Rubeus*: Es un conjunto de herramientas que interactúan directamente con kerberos y sus posibles abusos
- *Impacket/GetNPUsers.py*: Este script enumera, lista y recupera los TGT
