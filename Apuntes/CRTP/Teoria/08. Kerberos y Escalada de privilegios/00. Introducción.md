# Que es kerberos?
Kerberos es un protocolo de autenticación diseñado para permitir que dos entidades establezcan una clave secreta compartida de forma segura a través de un canal de comunicación inseguro.

Utiliza un centro de distribución de claves llamado *(KDC)* siendo este la autoridad central que gestiona la autenticación y emisión de tickets, siendo este una base de datos que contiene credenciales de usuario  e información principal del servicio, consta de dos componentes:
- *Servidor de autenticación (AS)*: Gestiona la autenticación inicial y emite un ticket de concesión de tickets (TGT) a otros usuarios tras una verificación exitosa
- *Servidor de concesión de tickets (TGS)*: Emite tickets de servicio (ST) a los usuarios que presentan un TGT valido, lo que permite el acceso a recursos específicos.

## Realm
Kerberos Realm es un limite de seguridad lógico donde la autenticación es administrada por un KDC especifico. En AD este se crea automáticamente cuando se inicia el dominio y se representa en mayúsculas como por ejemplo (*EXAMPLE.COM* para el dominio *example.com*) pero no es obligatorio.

Para identificar el dominio de un usuario se puede usar:
Para enumerar el nombre de inicio de sesión completo 
```shell
whoami /upn
```

Y para listar los tickets kerberos actualmente activos en la sesión
```shell
klist
```

## Principal
Kerberos Principal es una unidad única para la cual Kerberos puede emitir tickets, habiendo diferentes tipos:
- *Entidad principal de usuario*: Representando a un usuario individual (Nombre principal de usuario -> UPN)
		Se obtiene usando `whoami /upn`
- *Entidad principal de servicio*: Identifica un servicio que requiere autenticación
		Se obtiene usando `klist`
- *Entidad principal del host*: Representa un ordenador dentro del dominio Kerberos

Cada *Entidad principal de servicio* tiene una clave secreta para la autenticación.
