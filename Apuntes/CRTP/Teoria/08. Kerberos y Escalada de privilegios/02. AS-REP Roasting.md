Este tipo de ataques explota cuentas en las que la preautenticacion kerberos esta deshabilitada. EL estar en este estado el atacante puede solicitar un *Ticket Granting Ticket (TGT)* para el usuario objetivo y recibir un mensaje *AS-REP Cifrado* con el hash de la contraseña del usuario

##### Proceso
```ad-note
1) AS-REQ (Client -> KDC/AS)
   - Timestamp 🔑 Encrypted with Client key (only if preauthentication is enabled)

2) AS-REP (KDC/AS -> Client)
   - TGT 🔑 Encrypted with KDC key
   - TGS Session Key 🔑 Encrypted with Client key
```

En este caso podemos omitir el primer paso por que la preautenticacion esta deshabilitada, una vez que el atacante capture el *AS-REP* puede intentar descifrar la contraseña.

### 1. Revisar si las cuentas destino tienen deshabilitado la preautenticacion kerberos
```shell

Get-ADUser -Identity "asrep" -Properties DoesNotRequirePreAuth | Select-Object Name, DoesNotRequirePreAuth

# Opcion 2
Get-ADUser -Filter {DoesNotRequirePreAuth -eq $True} -Properties DoesNotRequirePreAuth

#PowerView
Get-DomainUser -PreauthNotRequired -Verbose
```
