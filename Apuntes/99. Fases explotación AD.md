
> Primero deberemos de abrir una CMD y en esta ejecutar una *InviShell*
> `RunWithRegistryNonAdmin.bat`
> 
> Segundo deberemos ejecutar *PowerView* `Powerview.ps1`
## Enumeración
### Dominio
#### Enumeración del dominio actual
```shell
Get-NetDomain
```
#### Enumeración de controladores de dominio
```shell
Get-NetDomainController
```

### Usuarios
#### Enumeración de usuarios
```shell
Get-NetUser | select cn
```
#### Enumeración usuarios marcados como administrador
```shell
Get-NetUser -AdminCount 1
```

### Grupos
#### Enumeración de grupos
```shell
Get-NetGroup
```
#### Enumeración miembros de un grupo
```shell
Get-NetGroupMember -GroupName "Domain Admins"
```

### Equipos
#### Enumeración de equipos de dominio
```shell
Get-NetComputer
```

### Relaciones de confianza
#### Enumeración de relaciones de confianza entre dominios
```shell
Get-NetDomainTrust
```

### ACL
#### Enumerar ACL para una cuenta de usuario especifica
```shell
Get-ObjectAcl -SamAccountName "Administrator" -ResolveGUIDs
```
#### Enumerar ACL asociadas a un objeto del dominio
```shell
Get-DomainObjectAcl -SearchBase "LDAP://CN=DomainAdmins,CN=Users,DC=dollarcorp,DC=moneycorp,DC=local" -ResolveGUIDs -Verbose
```
#### Enumerar ACL de un usuario que nos puedan resultar interesantes
```shell
Find-InterestingDomainAcl -ResolveGUIDs | ?{$_.IdentityReferenceName -match "student867"}
```
#### Obtener ACL de una ruta especifica
```shell
Get-PathAcl -Path "\\dcorp-dc.dollarcorp.moneycorp.local\sysvol"
```
### ACE
#### Enumerar ACE que puedan ser interesantes
```shell
Find-InterestingDomainAcl -ResolveGUIDs
```

### Recursos compartidos
#### Enumeración de recursos compartidos en los equipos del domino
```shell
Invoke-ShareFinder
```

### Configuración de delegación
#### Enumerar cuentas de usurario con SPN
```shell
Get-NetUser -SPN
```

### GPO
#### Enumerar GPOs del dominio actual
```shell
Get-DomainGPO
Get-DomainGPO | select displayname
Get-DomainGPO -ComputerIdentity dcorp-student1
```
