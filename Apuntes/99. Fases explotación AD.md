## Enumeración
### Dominio
#### Enumeración del dominio actual
```shell
Get-NetDomain
```
#### Enumeración de controladores de dominio
```shell
Get-NetDomainController
```

### Usuarios
#### Enumeración de usuarios
```shell
Get-NetUser | select cn
```
#### Enumeración usuarios marcados como administrador
```shell
Get-NetUser -AdminCount 1
```

### Grupos
#### Enumeración de grupos
```shell
Get-NetGroup
```
#### Enumeración miembros de un grupo
```shell
Get-NetGroupMember -GroupName "Domain Admins"
```

### Equipos
#### Enumeración de equipos de dominio
```shell
Get-NetComputer
```

### Relaciones de confianza
#### Enumeración de relaciones de confianza entre dominios
```shell
Get-NetDomainTrust
```
