> `RunWithRegistryNonAdmin.bat`
> 
> Segundo deberemos ejecutar *PowerView* `Powerview.ps1`
## Enumeración
### Dominio
#### Enumeración del dominio actual
```shell
Get-NetDomain
```
#### Enumeración de los controladores de dominio
```shell
Get-NetDomainController
```

### Usuarios
#### Enumeración de usuarios del dominio
```shell
Get-NetUser | select cn
```
#### Enumeración de usuarios marcados como administradores
```shell
Get-NetUser -AdminCount 1
```
