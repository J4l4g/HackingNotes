# ¿Qué es?
El *Information Disclosure (Divulgacion de Información)* es cuando una web revela de forma involuntaria información sensible a sus usuarios.
- Datos sobre otros usuarios
- Datos comerciales
- Datos técnicos sobre la web o infraestructura

Suele ser un punto de partida para exponer una superficie de ataque adicional en las cuales se pueden encontrar otras vulnerabilidades.
Ejemplos que son considerados *Information Disclosure*
- Revelación de nombres de directorios ocultos, su estructura y su contenido a través de un `robots.txt`
- Proporcionar acceso a código fuente a través de copias de seguridad
- Mencionar información sobre la base de datos en los mensajes de error
- Exponer información altamente confidencial
- API Keys en texto claro, direcciones IP, credenciales de bases de datos, etc, en el código fuente
- Insinuar la existencia de ausencia de recursos, nombres de usurarios, etc, a través de del comportamiento de la aplicación

# ¿Cómo surgen?
 Esta vulnerabilidad surge cuando hay la *Incapacidad de eliminar contenido interno publico*, *Configuración insegura del sitio web* o *Diseño defectuoso y comportamiento de la aplicación*
