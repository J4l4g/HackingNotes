# Cambiar de canal y frecuencia de la interfaz
## Cambiar canal
Al hacer un cambio de canal se ajusta la frecuencia al canal seleccionado
Primero deberemos de enumerar todos los canales disponibles de nuestra interfaz
```shell
iwlist wlan0 channel
```

Con al elección de canal que hagamos deberemos de deshabilitar primero la interfaz inalámbrica, seleccionar un canal, y volver a levantar la interfaz.
```shell
sudo ifconfig wlan0 down
```
```shell
sudo iwconfig wlan0 channel 64
```
```shell
sudo ifconfig wlan0 up
```

Verificaremos que todos los cambios se han efectuado correctamente
```shell
iwlist wlan0 channel
```

## Cambiar frecuencia
Al hacer un cambio de frecuencia se ajusta la frecuencia al canal en el que este alojada esa frecuencia
En este caso querremos cambiar únicamente la frecuencia a la que trabaje nuestra interfaz, teniendo que apagar primero la interfaz, configurar la nueva frecuencia y volver a levantarla
Primero antes de los pasos indicados deberemos de ver la frecuencia  ala que esta funcionando actualmente
```shell
iwlist wlan0 frecuency | grep Current
```

A continuación podremos proseguir con los siguientes pasos
```shell
sudo ifconfig wlan0 down
```
```shell
sudo iwconfig wlan0 freq "5.52G"
```
```shell
sudo ifconfig wlan0 up
```

Verificaremos si se ha cambiado la frecuencia y al canal acorde al cambio realizado
```shell
iwlist wlan0 frequency | grep Current
```


# Modos de Interfaz
### Managed Mode
Este modo se activa cuando queremos que nuestra interfaz actue como cliente o estacion, nos permite conectarnos y autenticarnos a un punto de acceso.
Se congigura de este modo de la siguiente forma
```shell
sudo ifconfigt wlan0 down
```
```shell
sudo iwconfig wlan0 mode managed
```

En caso de ahora querer conectarnos a una red podemos usar el siguiente comando
```shell
sudo iwconfig wlan0 essid WiFi-Named
```
