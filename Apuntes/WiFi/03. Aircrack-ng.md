# Introducción a la herramienta
*Aircrack-ng* comprende un conjunto de herramientas diseñadas para la evaluación de la seguridad de las redes WiFI.
Funcionalidades de la herramientas:
- *Monitoring* -> Captura de paquetes, permite también exportarlos para ser analizados en aplicaciones de terceros
- *Attacking* -> Ataques de replay, deauthentication, fake access points y otros ataques de inyección de paquetes.
- *Testing* -> Capacidad de comprobar las tarjetas de red y las capacidades de los drivers (Captura e inyección)
- *Cracking* -> WEP y WPA PSK

El paquete de *Arcrack-ng* contiene mas de 20 herramientas en su interior centrándonos actualmente únicamente en las 6 mas utilizadas y esenciales del paquete.

- *Arimon-ng* -> Capacidad de activar y desactivar el modo monitor en interfaces inalámbricas
- *Aridump-ng* -> Capacidad de capturar frames de 802.11 sin formato
- *Airgraph-ng* -> Capacidad de crear gráficos de redes inalámbricas a partir de archivos CSV generados por *Airdump-ng*
- *Airplay-ng* -> Capacidad de generar trafico inalámbrico
- *Airdecap-ng* -> Capacidad de descifrar archivos de capturas de red de *WEP*, *WPA PSK* o *WPA2 PSK*
- *Aricrack-ng* -> Capacidad de descifrar redes *WEP* y *WPA/WPA2* que utilicen claves pre-compartidas o *PMKID*

# Airmon-ng
Esta herramienta permite usar el modo monitor de nuestra tarjeta de red. Para mostrar información sobre nuestra tarjeta de red usaremos
```shell
sudo airmon-ng
```

Y para configurar nuestra tarjeta como modo monitor deberemos de hacerlo con
```shell
sudo airmon-ng start wlan0
```

Y comprobaremos si se ha habilitado correctamente el modo monitor con
```shell
iwconfig
```

### Comprobar procesos que interfieren
Puede haber procesos que interfieran en la ejecución de la herramienta los cuales los podemos detectar usando
```shell
sudo airmon-ng check
```

En caso de que estemos presentando dificultades con la intercepción de paquetes o con el pentest al usar la herramienta y queremos matar estos proceso solo tendremos que ejecutar después de el comando anterior la opción `kill`.

### Iniciar el modo monitor en un canal especifico
EN caso de querer arrancar esta herramienta en un canal especifico usaremos
```shell
sudo airmon-ng start wlan0 11
```


# Airodump-ng
Esta herramienta permite capturar paquetes en la trama 802.11 sin procesar. Su función principal es recopilar *IVs (Initialization Vectors)* en *WEP* o handshakes en *WPA/WPA2*, que posteriormente son usados por *aircrack-ng* para evaluar su seguridad
Esta herramienta proporciona gran cantidad de información de las redes WiFi
- *BSSID* -> Muestra la dirección MAC de los puntos de acceso
- *PWR* -> Muestra la potencia de la red. Cuanto mayor sea el numero mejor será la intensidad de la señal.
- *Beacons* -> Muestra el numero de paquetes de anuncios enviados por la red
- *#Data* -> Muestra el numero de paquetes de datos capturado
- *#/s* -> Muestra el numero de paquetes de datos capturados en los últimos 10 segundos
- *CH* -> Muestra el canal en el que se emite la red
- *MB* -> Muestra la velocidad máxima que admite la red
- *ENC* -> Muestra el método de cifrado usado por la red
- *CIPHER* -> Muestra el cifrado utilizado por la red
- *AUTH* -> Muestra el método de autenticación usado por la red
- *ESSID* -> Muestra el nombre de la red
- *STATION* -> Muestra la dirección MAC del cliente conectado a la red
- *RATE* -> Muestra la tasa de transferencia de datos entre el cliente y el AP
- *LOST* ->  Muestra el numero de paquetes de datos perdidos
- *Packets* -> Muestra el numero de paquetes de datos enviados por el cliente
- *Notes* -> Muestra información adicional sobre el cliente como el *EAPOL* y *PMKID* capturados
- *PROBES* -> Muestra la lista de redes que el cliente esta buscando

Para utilizar esta herramienta correctamente lo primero que hay que hacer es activar el modo monitor en la interfaz, así que lo activaremos con *Arimon-ng*
```shell
sudo airmon-ng start wlan0
```

Una vez activado el modo monitor podremos ejecutar ya la herramienta de *Airdump-ng* y empezar escanear y recopilar datos sobre los accesos inalámbricos detectables en la interfaz seleccionada
```shell
sudo airodump-ng wlan0
```
### Escanear solo un canal
En caso de que queramos escanear solo un canal especifico, para usar una frecuencia especifica podemos indicar el canal usando la opción `-c <num_channel>`
### Indicar banda de escaneo
También podemos escanear diferentes bandas WiFi, utilizando la opción `--band`, e indicaremos la banda a escanear
- *a* -> 5GHz
- *b* -> 2.4 GHz
- *g* -> 2.4 GHz

En caso de querer usar las tres bandas podemos indicar las letras una detrás de otra sin comas ni espacios
### Guardar resultado
Para guardar el resultado del escaneo usaremos la opción `--write <nombre-file>` generándose así diferentes archivos con el mismo nombre pero diferente formato de archivo

# Airgraph-ng
Esta herramienta utiliza los archivos generado por *Airodump-ng* y procesa estos archivos *CSV* para producir dos tipos de gráficos distintos
- *Grafico de relación entre clientes y puntos de acceso* -> Estos gráficos representas las conexiones entre los clientes inalámbricos y los puntos de acceso, proporcionado información sobre la topología de red y las iteraciones entre los dispositivos
- *Grafico de sondeo de clientes* -> Estos gráficos muestran una representación visual de las redes escaneadas y a las que potencialmente acceden los dispositivos de los clientes.
Esta herramienta facilita la capacidad de visualizar y analizar las relaciones e interacciones dentro de las redes inalámbricas

## Grafico de relación entre clientes y AP (CAPR)
El grafico de *Clients to AP Relationship (CAPR)* ilustra conexiones entre los clientes y los puntos de acceso. Dado que este grafico se centra en los clientes no mostrara ningún punto de acceso sin clientes conectados.
Los puntos de acceso están codificados por colores según su tipo de cifrado.
- *Verde* -> WPA
- *Amarillo* -> WEP
- *Rojo* -> Redes abiertas
- *Negro* -> Cifrado desconocido

Para generar las imágenes a partir de los *CSV* usaremos
```shell
sudo airgraph-ng -i <file.csv> -g CAPR -o <out-file.png>
```

# Aireplay-ng
La función principal de esta herramienta es generar trafico para uso posterior uso en *aircrack-ng*, y así poder descifrar las claves *WEP* y *WPA-PSK*.
Existen diferentes ataques que permite la desautenticación con el fin de capturar los datos del handshake *WPA*, autenticaciones falsas, preproducción interactiva de paquetes, inyección de solicitudes ARP elaboradas manualmente y reinyección de solicitudes ARP.

Para listar todas las utilidades de la herramienta usaremos
```shell
aireplay-ng
```

Esta herramienta tienes varias opciones de ataques
- *Attack 0*	Desautenticación
- *Attack 1*	Autenticación falsa
- *Attack 2*	Reproducción interactiva de paquetes
- *Attack 3*	ataque de repetición de solicitud ARP
- *Attack 4*	Ataque de KoreK chopchop
- *Attack 5*	Ataque de fragmentación
- *Attack 6*	Ataque de café con leche
- *Attack 7*	Ataque de fragmentación orientado al cliente
- *Attack 8*	Modo de migración WPA
- *Attack 9*	Prueba de inyección

A la hora de ejecutar cada tipo de ataque se indica con `-<num-attack>`

## Deauthetication attack
### Packet Injection
Antes de enviar las tramas de desautenticacion, es importante verificar que nuestra tarjeta de red puede inyectar tramas correctamente en el AP objetivo.
Primero  habilitaremos el modo monitor y configuraremos el canal de la interfaz en el 1.
```shell
airmon-ng start wlan0 1
```
 También podemos usar iw
 ```shell
 sudo iw dev wlan0 set channel 1
 ```

Ahora tendremos que hacer una prueba para ver si nuestra tarjeta de red esta trabajando en el modo de inyección de paquetes.
```shell
sudo aireplay-ng --test wlan0
```

Si todo esta funcionando correctamente saldra un mensaje de *Injection is working!*, indicando esta estamos listo para iniciar un *deauthentication attack*
