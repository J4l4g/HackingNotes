# Tipos de autenticación
La autenticación frente a una red WiFi es esencial para proteger las redes inalámbricas y los datos frente al acceso no autorizado.
Los principales tipos son *WEP*, *WPA*, *WPA2* y *WPA3*, siendo cada uno una progresión en laso estándares de seguridad
![[Pasted image 20260728221435.png]]

- *WEP (Wired Equivalent Privacy)* -> Es el protocolo de seguridad WiFi original. Proporciona un cifrado basico, en la actualidad se considera obsoleto e inseguro debido a vulnerabilidades conocidas que lo hacen facil de vulnerar.
- *WPA (WiFi Protected Access)* -> Fue introducido como una mejora provisional sobre *WEP*, ofreciendo un mejor cifrado a traves de *TKIP (Temporal Key Integrity Protocol)*, pero sigue siendo uno
