# Tipos de autenticación
La autenticación frente a una red WiFi es esencial para proteger las redes inalámbricas y los datos frente al acceso no autorizado.
Los principales tipos son *WEP*, *WPA*, *WPA2* y *WPA3*, siendo cada uno una progresión en laso estándares de seguridad
![[Pasted image 20260728221435.png]]

- *WEP (Wired Equivalent Privacy)* -> Es el protocolo de seguridad WiFi original. Proporciona un cifrado básico, en la actualidad se considera obsoleto e inseguro debido a vulnerabilidades conocidas que lo hacen fácil de vulnerar.
- *WPA (WiFi Protected Access)* -> Fue introducido como una mejora provisional sobre *WEP*, ofreciendo un mejor cifrado a través de *TKIP (Temporal Key Integrity Protocol)*, pero sigue siendo uno de los estándares menos seguros respecto a los nuevos.
- *WPA2 (WiFi Protected Access II)* -> Un avance significativo sobre *WPA* usando una encriptación *AES (Advanced Encryption Standar)*, proporcionando una seguridad robusta. Ha sido el estándar durante muchos años proporcionando una fuerte protección para la mayoría de las redes.
- *WPA3 (WiFI Protected Access III)* -> Es el estándar mas reciente, mejora la seguridad con características como el cifrado de datos de forma individualizada y una autenticación basada en contraseña mas robusta, lo que la convierte en la opción mas segura actualmente.

#### Puntos a evaluar en una red WiFi
- Evaluación de contraseñas para determinar su resistencia y seguridad
- Analizar la configuración para identificar vulnerabilidades
- Analizar la infraestructura de la red en busca de vulnerabilidades
- Pruebas en los dispositivos de los clientes para detectar posibles fallos de seguridad

A continuación de explican mas a detalle estos puntos a evaluar:
1. *Evaluacion de contraseñas* -> Esto implica evaluar la solidez y seguridad de as contraseñas o frases de acceso de las redes WiFi. Empleando diferentes tácticas, como ataques de diccionario, ataques de fuerza bruta y herramientas para descifrar contraseñas, para analizar la resistencia de las contraseñas frente a un acceso no autorizado.
2. *Evaluación de configuración* -> Se centra en analizar la configuración de los *routers* y *AP (Access Point)* para identificar posibles vulnerabilidades de seguridad. Esto incluye examinar minuciosamente protocolos de cifrado métodos de autenticación, segmentación de red y otros parámetros de configuración para garantizar que cumplan con las mejores practicas de seguridad.
3. *Evaluación de la infraestructura* -> Esta fase se centra en evaluar la robustez de la infraestructura de la red WiFi. Realizando evaluaciones exhaustivas para descubrir vulnerabilidades en la arquitectura de res, las configuraciones de los dispositivos, las versiones de firmware y los fallos de implementación que podrían ser explotados por atacantes para comprometer la red.
4. *Evaluación de los clientes* -> Se evalúa la seguridad de los clientes WiFi, como portátiles, teléfonos y dispositivos IoT, que se conectan a la red. Implicando buscar vulnerabilidades en el software cliente, los sistemas operativos, controladores inalámbricos y las implementaciones de la pila de red para identificar posibles puntos de entrada para los atacantes.
