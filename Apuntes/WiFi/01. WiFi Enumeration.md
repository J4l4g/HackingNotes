# Buscando redes WiFi disponibles
Para escanear las redes WiFi disponibles en nuestro alrededor, usaremos el comando `iwlist` indicándole la interfaz sobre la que hacer el escaneo y ya que ofrece una extensa salida es recomendable filtrar la salida para mostrar únicamente la información mas relevante
```shell
iwlist wlan0 scan | grep 'Cell\|Quality\|ESSID\|IEEE'
```

## Cambiar de canal y frecuencia de la interfaz
Primero deberemos de enumerar todos los canales disponibles de nuestra interfaz
```shell
iwlist wlan0 channel
```
